# SolverForge

**Nemotron reasons. Nebius executes. Tests verify. Measurements decide.**

SolverForge is an autonomous AI-powered algorithm engineering agent that treats code optimization as an experimental process. Instead of only suggesting faster code, SolverForge analyzes a program, generates optimization hypotheses, implements candidate changes, executes them in isolated sandboxes, verifies correctness, benchmarks performance, and uses the experimental results to decide what to try next.

SolverForge is designed for computationally intensive problems such as combinatorial optimization, graph algorithms, SAT/CP-SAT solvers, search algorithms, and other performance-sensitive software.

The project uses NVIDIA Nemotron for reasoning and code generation and Nebius Token Factory for model access and sandboxed execution.
